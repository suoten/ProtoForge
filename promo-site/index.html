30 秒启动，浏览器即用

不需要装 Python、Node.js、Git——Docker 一行，或 Windows 便携包双击。
# Docker：一条命令，全套虚拟设备拉起
docker run -d --name protoforge -p 8000:8000 suoten/protoforge:latest

# 或 pip（v1.16 起分发名 protoforge-sim，避免 PyPI 同名假包）
pip install protoforge-sim

# Windows 便携包：双击即用，配置随目录走
