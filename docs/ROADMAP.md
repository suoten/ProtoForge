# ProtoForge 版本路线图

> 基线：v1.11.1（2026-11-01）。本路线图公开，欢迎在 Issues 中讨论与投票。
> 节奏：约 2~4 周一个 minor 版本；企业需求可走付费加急通道优先排期。

## 设计原则

1. **开源版永不做削弱**：不在开源版上增加时间锁、设备数限制、协议锁。企业版只做增量闭源模块 + 专业服务。
2. **需求驱动 60% + 战略驱动 40%**：issue 热度决定多数排期，但插件化、企业边界、平台化这三件战略事必须按路线推进。
3. **每个版本都要能单独变现或单独获客**：不做"只对内部有意义"的版本。

## 路线

### v1.12 「信任与转化」（2026-11-09 ✅ 已发布）

- ✅ **PyPI 分发名启用 `protoforge-sim`**：`pip install protoforge-sim`，安装后命令行仍为 `protoforge`（`protoforge run/doctor/desktop` 等零变化）；CI 恢复 PyPI 真实发布（配置 `PYPI_API_TOKEN` 后生效，未配置自动降级为仅构建验证）。PyPI 上被占用的 `protoforge`（无关项目）已在 README/TRADEMARK 声明警示。
- ✅ README / README_EN 安装指令全面校正 + 数据一致性修复（模板统一 133、协议统一 31、开源版/企业版对比表与实际功能对齐、MQTT 版本表述校准）。
- ✅ 新增 [TRADEMARK.md](../TRADEMARK.md)：品牌归属、官方渠道清单、使用规范与仿冒举报渠道。
- ✅ 新增本路线图并公开。
- ⏳ 人工推进项：商标注册申请（第 9 类软件 / 第 42 类技术服务）、官网服务/案例落地页、QQ 群与 issue 案例库挖掘。
- 📌 是否进一步统一品牌（仓库/镜像/CLI 全量迁移到独立新词）挂起评估：先观察 PyPI 申诉（PEP 541）与社区反馈，不折腾存量用户。

### v1.13 「AI 入口」— 最低成本的新流量

- ✅ **ProtoForge MCP Server**（v1.13.0，2026-11-09 发布）：21 个工具 + 1 资源 + 1 引导 prompt，`protoforge mcp` 一条命令拉起；Claude Desktop / Cursor 开箱即配置，AI 可直接完成 搜模板 → 建设备 → 读写点位 → 跑断言 → 取连接指南 的验证闭环。实现为 SDK 薄包装，权限复用 RBAC。
- ✅ **AI 点表/说明书导入**（v1.13.1，2026-11-09）：LLM（默认本地 Ollama，OpenAI 兼容服务可切换）解析说明书原文 → 可复核点表（notes 标注歧义）→ 一键建设备；`protoforge ai` 三命令 + 2 个 MCP 工具 + 2 个 REST 端点 + SDK 方法。Web 界面集成排期 v1.14。
- ✅ **AI 调试排障**（v1.13.4，2026-11-14）：调试日志 → LLM 结构化诊断，**每条结论必须引用真实日志行作证据**（无出处结论丢弃）；`protoforge ai diagnose` + 1 个 MCP 工具 + REST 端点。
- ✅ **Web 界面 AI 入口**（v1.14.0，2026-11-14）：点表导入向导「AI 解析说明书」模式（结果灌入同一预览管线）+ 调试日志「AI 诊断」按钮——浏览器用户与 CLI/MCP 用户同等可用，v1.13 AI 闭环真正闭合。

### v1.15 「插件化」— 生态容器

- ✅ **插件系统**（v1.15.0，2026-11-14）：`data/plugins/` 目录 + entry_points 双来源，manifest 声明协议/模板/端口，注入既有注册管道零侵入；`GET /plugins` 透明展示；示例电力行业包（10kV 电表 + FTU，`examples/plugins/`）随源码分发。**容器开源、内容双轨**：基础包免费随开源版，定制行业内容作为独立交付物。
- ⏳ 模板市场 v1：社区提交模板 + 官方审核通道，贡献者署名（插件加载机制已就绪，剩余为审核流程与展示页）。

### v1.16 「协议纵深」

- README 开源版/企业版对比表与实际交付物完全对齐。

### v2.0 「平台」（2027 Q2）

- **仿真农场**：一台控制端调度 N 台执行器，跨机器大规模仿真（千级设备分布式）。
- **云沙箱**：按 PR/按任务拉起 ephemeral 仿真环境的托管 API——CI 仿真即服务，SaaS 雏形。
- 企业版正式 GA + 公开定价；国际站（英文文档完善 + DNP3 + Stripe/GitHub Sponsors）。
